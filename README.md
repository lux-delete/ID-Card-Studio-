# ID Card Studio

A free, single-file ID card designer that runs entirely in your browser. No sign-up, no server, no tracking.

## Features
- 11 ready-made templates (vertical and horizontal) with a Surprise me button
- Live preview of front and back, with a flip animation
- Photo and logo upload, drag to reposition, scroll to zoom, drop or paste an image
- Colours, fonts, header shapes, patterns, barcode and signature line
- Basic and Advanced modes
- Undo and redo, autosave, light and dark theme
- Download PNG, print or save as PDF, export and import a design file

## Use it
Open `index.html` in any modern browser, or host it with GitHub Pages (Settings, Pages, deploy from the main branch).

## Shortcuts
Ctrl/Cmd+Z undo, Ctrl/Cmd+Shift+Z redo, Ctrl/Cmd+S download design file, Esc back to templates.

## Notes
Fonts load from Google Fonts and PNG export loads html2canvas from cdnjs the first time it is used. Your data stays on your device.
